Instructions to operate the application TowerFlow
-------------------------------------------------

Step 1: Starting fresh from .Zip file or from Repository
 A: Use a new(empty) folder to install the files avaliable into the folder provided.

 B: Verify the route of the files then press "Clone" after selection of the proper "Local path" shown.

 Step 2: After the file has been clone it shall display the name of the folder
 "2610_Team02".

 A: Click and open the file from here. A list of files will be displayed.

 B: From here select the folder "TowerFlowWindow" then proceed to open "TowerFlowWinForm".

 C: Now the application will be shown as "TowerFlowWinForm.slnx" then select it right click "Open with", Now Select "(Microsoft) Visual Studio.

 Step 3: You can now Press "Ctrl+F5 / F5" to now run the application

 A: If your screen displays the blank layout, look at the View in the top bar and open the Solution Explorer and select the files provided to make editions.

 Happy TowerFlow.
