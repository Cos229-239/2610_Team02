# Azure Flow is an isolated read-only business frontier

**Status: accepted for prototype.** TowerFlow's existing stock ledger, authentication and Azure Stock Guide's protected preview/confirm remain the authoritative write model. Azure Flow receives a separate tab and a narrowly allowlisted authenticated read-only evaluation endpoint, instead of modifying other tabs or allowing a generative model to issue commands. This choice trades unconstrained automation for reproducible evidence, safer collaboration and preservation of existing work.
